# Mero Bhajan

Mero Bhajan — मेरो भजन — Nepali Christian songbook with lyrics and chords.

This is the public, read-only GitHub Pages version. It contains the 10 starter
songs with verse and chorus split, chords above the words in English letters
plus the Nepali (Devanagari) script, categories, Nepali alphabet browsing,
search, transpose, font size, English / Nepali / Both word display, and
favorites saved only in the visitor's browser.

There is no admin login and no song suggestions on this page. Those live in
the Muse app, where the admin reviews suggestions before anything goes live.

To suggest a song or a correction, use the Suggest a song button in the
Mero Bhajan app, or open an issue in this repository.

Live site: https://tamangk.github.io/merobhajan/
